# AI Fitness Trainer

A platform for personalized workout and nutrition plans combining AI efficiency with human expertise.

## Features
- User onboarding with goals, lifestyle, and optional body measurements
- AI-generated weekly workout and daily nutrition plans
- Exercise library with video demonstrations
- Progress tracking
- Optional coach check-ins

## Tech Stack
- Frontend: React, Vite, TypeScript, Tailwind CSS
- Backend: Node.js, Express, PostgreSQL (Prisma ORM)
- AI Service: Python, FastAPI
- More details in docs/
